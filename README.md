# CRUDS - Product Management System

A Web-based Product Management System that performs full **CRUDS** operations (Create, Read, Update, Delete, and Search) to manage products and inventories seamlessly.

## 🚀 Features
- **Create:** Add new products with title, price, taxes, ads, discount, and total calculation.
- **Read:** Display all stored products in a structured table.
- **Update:** Edit existing product details easily.
- **Delete:** Remove a single product or clear the entire product list.
- **Search:** Search products by Title or Category instantly.
- **Data Persistence:** All product data is saved in `LocalStorage`.

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla JS)
